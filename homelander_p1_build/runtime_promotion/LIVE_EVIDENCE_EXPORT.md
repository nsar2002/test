# Live Evidence Exporter\n\nUse this after closing Prototype following a live gate attempt.\n\nThe exporter is read-only with respect to gameplay and promotion state. It validates the active managed ASI and loader identity, then creates one ZIP containing the evidence needed for audit:\n- homelander_p1_runtime.log, when present\n- .homelander_promotion/state.json, when present\n- authoritative receipts, when present\n- Live Gate Assistant session/candidates, when present\n- EVIDENCE_SUMMARY.json with active-stage/build/gate and file SHA256 identities\n\nIt deliberately does not copy rollback backups or modify passedStages.\n\nRun: P1_EXPORT_LIVE_EVIDENCE.cmd\n\nOutput: .homelander_promotion\\evidence_exports\\\n\nA matching .sha256.txt file is produced beside every evidence ZIP.
