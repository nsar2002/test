The original F20 DOT dry-run scheduler requires only F19 continuity boolean and NPC GOH, so user-player B can borrow the actual F17/F18/F19 proof earned by originating player A if both can aim at NPC. The old F20 will issue enough diagnostic WOULD_DAMAGE events and publish F20 PASS for player B, despite the original damage/continuity chain belonging to A. The old F20 can also retain its previous F20 PASS when a new activation fails, exposing a stale F21 prerequisite.

A new guarded F20 requires HOMELANDER_DOT_DRYRUN_PLAYER to be bound to HOMELANDER_TARGET_CONTINUITY_PLAYER and HOMELANDER_DAMAGE_LAST_PLAYER. It checks that current player, NPC target, F17, F18 and F19 lineage remain unchanged before and after tick health/camera/LOS/target callbacks. Each new activation invalidates prior F20 pass immediately, and aborting an active dry-run revokes the proof. A successful dry-run publishes its exact player identity for a paired guarded F21 to consume; no actual game damage or visual effect API is invoked by F20.
