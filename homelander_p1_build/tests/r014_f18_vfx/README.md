# R014 F18 world-effect source-only irreversible submission reservation

The original F18 impact_vfx_gate_v012_STAGED.lua sets HOMELANDER_IMPACT_VFX_SUBMITTED only AFTER pcall(em_AddWorldEffect). The native bridge can synchronously call the F18 Lua entrypoint from within em_AddWorldEffect, causing duplicate one-shot effects. A void world effect can also mutate and then throw, and a prior F18 would leave F17 proof available for unsafe retry. An actual-old-source Lua5.1 mock reproduces the two effect submissions.

New impact_vfx_gate_v012_reserved_DORMANT.lua increments a monotonic F18 attempt counter, validates exact F17 success and source impact position before mutating, sets HOMELANDER_IMPACT_VFX_RESERVED=true and consumes HOMELANDER_DAMAGE_ONESHOT_PASSED BEFORE the native effect call, preventing nested F18/retry after an uncertain native outcome. If em_AddWorldEffect throws, it returns false with reservation consumed and HOMELANDER_IMPACT_VFX_SUBMITTED=false (no unearned F19 proof). It only publishes F18 success metadata after the native binding returns. Pre-submit invalid effect scale or replaced source hit point does NOT consume the valid upstream F17 proof, allowing a corrected safe attempt.

The R014 old/new actual source mock covers two old native submissions, one new native submission, exception-after-effect consumed with F19 blocked, invalid scale safe retry and changed F17 world hit refusing before native submission. The complete source-only 22-native-path assembler now atomically maps NINE guarded source variants F9/F10/F11/F12/F14/F15/F16/F17/F18, preserving the other 13 modules and original four v003 baseline Lua scripts unchanged. Native C++ unchanged and compiled in scratch only; no stage ZIP, original R007 manager/manifest, active game root or installed binary changed.

Conservative limitation: the reservation persists only for the current Lua state. A native effect may have rendered even when its void binding raises; neither code nor mock proves real visual output. Real first game gate remains original R007 v003 BOOT/F4/F9 then close game/manager Check; later F17/F18 mutations must not be promoted based on mocks.
